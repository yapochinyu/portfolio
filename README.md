# Портфолио: аналитика данных и ML

## Основной проект

### [Прогнозирование сердечно-сосудистых заболеваний](heart-disease-prediction)

Демонстрационный модуль, разработанный в рамках производственной практики для
Медицинского информационно-аналитического центра РСО-Алания (МИАЦ). Единственный
проект с внешним заказчиком: не только модель, но и рабочий сервис — обученный
пайплайн обёрнут в API на FastAPI, который можно вызвать из внешней системы.

**Задача:** по клиническим показателям, доступным уже на амбулаторном приёме,
оценить риск сердечно-сосудистого заболевания — чтобы понять, кого направлять
на углублённое обследование в первую очередь.

**Результат:** Random Forest, ROC-AUC 0.92 и Recall 0.91 на отложенной тестовой
выборке (метрики воспроизводят кросс-валидацию — переобучения нет). Recall
приоритетнее точности осознанно: пропустить больного дороже, чем перепроверить
здорового.
