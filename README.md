# Портфолио проектов по анализу данных

Проекты выполнены в рамках обучения на курсе «Специалист по Data Science» (Яндекс.Практикум). Каждый проект — законченный кейс: от постановки задачи и предобработки данных до проверки гипотез или обучения ML-модели с оценкой качества по заданной метрике.

## Проекты

| Проект | Тип задачи | Метрика | Результат |
|---|---|---|---|
| [GoFast: аренда самокатов](gofast-scooter-analytics) | EDA, статистика, проверка гипотез | — | 4 гипотезы проверены t-тестами |
| [HR-аналитика](hr-satisfaction-attrition) | ML: регрессия + классификация | SMAPE ≤ 15 / ROC-AUC ≥ 0.91 | SMAPE 14.9 / ROC-AUC 0.929 |
| [Прогноз заказов такси](taxi-demand-forecast) | Временной ряд | RMSE ≤ 48 | RMSE 44.1 (LightGBM) |
| [Отток клиентов телекома](telecom-churn-prediction) | ML: бинарная классификация | ROC-AUC ≥ 0.85 | ROC-AUC 0.922 (CatBoost) |

## Стек

Python, pandas, numpy, scipy, scikit-learn, LightGBM, CatBoost, matplotlib, seaborn, SQL

## Структура

Каждая папка — независимый проект: `analysis.ipynb` с кодом и выводами, `data/` с исходными данными, `README.md` с описанием задачи и результатов.
