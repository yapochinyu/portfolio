# Прогнозирование заказов такси в аэропортах

Модель временного ряда для прогноза числа заказов такси на следующий час — чтобы привлекать больше водителей к периоду пиковой нагрузки.

## Задача

Спрогнозировать `num_orders` на час вперёд. Критерий успеха — RMSE ≤ 48 на тестовой выборке (10% данных, без перемешивания).

## Данные

- `data/taxi.csv` — исторические заказы такси с меткой времени

## Что сделано

- Ресемплирование данных по часу
- Анализ тренда, сезонности и автокорреляции временного ряда
- Генерация признаков (лаги, скользящее среднее, календарные признаки)
- Обучение и сравнение моделей: линейная регрессия, случайный лес, LightGBM
- Проверка лучшей модели на тестовой выборке

## Результаты

Сравнение моделей по RMSE (валидация):
- Linear Regression — 31.6
- Random Forest — 27.9
- LightGBM — 26.3

Лучшая модель — **LightGBM**, RMSE на тесте: **44.1** при пороге ≤ 48.

## Стек

Python, pandas, statsmodels, scikit-learn, LightGBM, matplotlib
