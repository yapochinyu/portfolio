# HR-аналитика: удовлетворённость и отток сотрудников

Две ML-задачи для HR-отдела: предсказание уровня удовлетворённости сотрудника работой и предсказание вероятности его увольнения, на основе характеристик из внутренних систем компании.

## Задача

1. **Регрессия**: предсказать `job_satisfaction_rate` (0–1) по характеристикам сотрудника. Критерий успеха — SMAPE ≤ 15.
2. **Классификация**: предсказать `quit` (уволится/останется), используя в том числе предсказанный уровень удовлетворённости как признак. Критерий успеха — ROC-AUC ≥ 0.91.

## Данные

- `data/train_job_satisfaction_rate.csv`, `data/test_features.csv`, `data/test_target_job_satisfaction_rate.csv` — задача 1
- `train_quit.csv`, `test_target_quit.csv` — задача 2 (файлы выдаются на платформе Практикума отдельно, здесь не хранятся)

Признаки: отдел, должность, загруженность, стаж, повышения/нарушения за год, оценка руководителя, зарплата.

## Что сделано

- Предобработка и EDA обоих датасетов, портрет уволившегося сотрудника
- Пайплайны с несколькими кодировщиками категориальных признаков
- Задача 1: линейная модель и решающее дерево, подбор гиперпараметров
- Задача 2: три модели, включая использование предсказания из задачи 1 как нового признака
- Проверка адекватности моделей относительно `DummyClassifier`

## Результаты

- Задача 1 (SMAPE, тест): **14.9** при пороге ≤ 15
- Задача 2 (ROC-AUC, тест): **0.9286** при пороге ≥ 0.91 (для сравнения: DummyClassifier — 0.4975)
