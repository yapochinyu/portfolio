# GoFast: анализ данных и проверка гипотез сервиса аренды самокатов

Статистический анализ пользователей и поездок сервиса кикшеринга GoFast: EDA, объединение данных, расчёт помесячной выручки и проверка бизнес-гипотез с помощью статистических тестов.

## Задача

Сервис хочет увеличить долю пользователей с подпиской Ultra. Нужно изучить поведение подписчиков и обычных пользователей и проверить, действительно ли подписчики выгоднее для бизнеса.

## Данные

- `data/users_go.csv` — пользователи (город, возраст, тип подписки)
- `data/rides_go.csv` — поездки (расстояние, длительность, дата)
- `data/subscriptions_go.csv` — тарифы (цена минуты, старта, абонплата)

## Что сделано

- Предобработка: дубликаты, типы данных, аномалии в длительности поездок
- EDA: распределения по городам, возрасту, подписке, расстоянию и длительности поездок
- Расчёт помесячной выручки по каждому пользователю
- Проверка гипотез (t-тесты, односторонний тест): длительность поездок подписчиков и без подписки, среднее расстояние поездки против оптимального порога 3130 м, помесячная выручка по группам

## Результаты

- Пользователи с подпиской ездят дольше и приносят больше выручки в месяц, чем пользователи без подписки
- Среднее расстояние поездки подписчиков не превышает оптимальные для износа самоката 3130 м
- Суммарная выручка сервиса за год — 3,88 млн ₽

## Стек

Python, pandas, numpy, matplotlib, seaborn, scipy.stats
