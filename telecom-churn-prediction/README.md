# Прогноз оттока клиентов оператора связи «ТелеДом»

Модель машинного обучения для оператора связи, предсказывающая вероятность того, что абонент разорвёт договор — чтобы заранее предлагать таким клиентам промокоды и спецусловия.

## Задача

Построить модель прогноза оттока на основе персональных данных, тарифов и подключённых услуг. Критерий успеха — ROC-AUC ≥ 0.85 на тестовой выборке; дополнительно оцениваются accuracy, матрица ошибок и важность признаков.

## Данные

Данные хранятся в SQLite (`data/ds-plus-final.db`), 4 таблицы: `contract`, `personal`, `internet`, `phone`, объединённые по `customerID`.

## Что сделано

- Загрузка из SQLite, проверка и объединение таблиц по клиенту
- EDA объединённой таблицы, обработка аномалий, корреляционный анализ
- Генерация признаков (например, длительность контракта) без утечки целевого признака
- Сравнение классов моделей: деревья/случайный лес, бустинги, нейросети
- Автоматизированный подбор гиперпараметров (кросс-валидация)
- Анализ важности признаков и зависимости целевой переменной от ключевого признака

## Результаты

Лучшая модель — **CatBoost**:
- ROC-AUC на кросс-валидации: **0.8993**
- ROC-AUC на тесте: **0.922** при пороге ≥ 0.85

## Стек

Python, pandas, SQLAlchemy/SQLite, scikit-learn, CatBoost, matplotlib, seaborn
